What

Adds a Forge-backed pull-request inbox and a persistent review surface beside active ocode sessions. Pull requests can be opened as peer tabs without leaving the agent workspace.

How

  • Forge resolves every request against the project’s canonical remote.
  • Summary and activity use short-lived cached reads; large diff slices travel over bounded HTTP responses.
  • The browser stores only shallow surface references such as project/repository#number.
  • Agent handoffs treat PR titles, branches and review text as untrusted context.
