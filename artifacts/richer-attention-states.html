Recommended model

Two signals,
not one noisy badge.

A thread’s current state and whether it has been seen are different facts. Showing both makes the sidebar useful without turning it into a dashboard.

The dot means “new since you looked.” The colored word says what is true right now: Approval, Input, Done, Failed, or Working.
Unread signal

Dot + stronger title. Clears when the visible thread is read; can be restored with Mark unread.

Attention state

Persistent semantic color and label. Approval/Input remain until resolved—even after viewing.

Visual priority

01Approval / Input — actionable now; always legible.
02Done / Failed + unread — new outcome waiting to be reviewed.
03Working — informative, but visually quieter.
04Read and idle — recedes naturally without disappearing.

Concept only. It keeps Anvil’s existing row structure, project filters, settled section, and restrained visual language.
